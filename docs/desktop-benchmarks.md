# Desktop 实际资源测速与定时切换

管理器主窗口或托盘中的「Desktop 测速 / 定时」会打开测速窗口。原网页版的三个 Desktop 实际资源和两个匿名入口已经移植，测试不依赖 Clash Verge，不需要登录或发送聊天。

## 测试内容

默认清单来自 2026-10-25 的 Desktop 资源观测：界面模块 JS、曾出现部分下载的较大 JS、样式 CSS、Claude 网页入口和 API 匿名根入口。

每个节点通过独立临时 Mihomo 监听进行测试，生产 `17987` 和当前选择保持独立。测试内核使用相同的批准身份、固定核心哈希及物理网卡/DNS 绑定，不启用 TUN 或其他管理端口。测试结束、取消或管理器退出会清理自有测试内核。

记录每个节点 × 目标 × 协议 × 轮次的结果：HTTP 状态、实际协议、完整性、接收/预期字节、内容类型、TTFB、总耗时和失败原因。HTTP/1.1 与 HTTP/2 分开请求，HTTP/2 协商失败不降级算通过。单项响应上限 8 MiB，不使用账号 Cookie、Authorization 或客户端证书，不跳过服务器证书验证。

默认参数为两种协议、3 轮、单项整体超时 30 秒、并发 2 个节点，可编辑。14 个节点对应 420 个样本；完整资源下载会产生实际订阅流量。

## 全通过与最佳节点

- 资源必须完整、非空、HTTP 2xx，类型为要求的 JS/CSS；状态 200 但下载中断或返回 HTML 都失败。
- 匿名入口的完整 2xx/3xx 表示入口可达，不跟随重定向。仅 API 根地址的 404 视为预期匿名可达；它不表示真实 API 调用成功。403、429 和服务端错误不通过。
- 每个要求的目标、协议、轮次必须恰有一个通过样本。缺失、重复、取消、部分下载或历史上只测了其中一种协议，都不算全通过。
- 先排全通过节点；之后按通过目标/样本数、最差目标中位耗时、平均中位耗时、最慢样本、自然名称排序。自动切换只从全通过候选中选择，部分通过排名不构成切换许可。

匿名入口 403 可能与访问限制有关；它不直接证明 Desktop 登录会话不可用，也不是 IP 或账号安全评分。

全通过也不验证实时出口地区。节点身份批准、这些请求的测试结果、主窗口的出口地区检查是不同的观测。

## 定时设置

定时测试默认开启，间隔 **24 小时**；可编辑为 0.1–8760 小时。首次升级从当前时间起算，不立即批量测速。保存新的间隔后重新起算；重开管理器保留原下次时间。

管理器运行或驻留托盘时才执行定时测试；退出后不运行。重新打开后若已到期，执行一次，不补跑全部错过的周期。任务不重叠；一次测试超过间隔时，完成后重新安排，避免连续补跑。关闭测速子窗口不取消测试。

## 自动切换

**默认关闭**，需在测速窗口明确勾选并保存。只对新完成的定时全量测试生效：

1. 当前节点全部通过：继续使用，即使其他节点更快。
2. 当前节点未全通过：切到全通过候选中排名最佳者，并关闭专用内核原有连接，使重连使用新节点。
3. 没有全通过候选：切到 REJECT，不使用部分通过或 DIRECT 后备。

停止的生产内核不会被测试自动启动，手动 REJECT 不会被自动解除。手动测速始终只更新结果。

取消、任务失败、资源 URL 失效、样本矩阵不完整、测试期间手动选择/停止或修改批准名单、网卡、参数等情况均跳过自动动作。完成时重新检查当前生产进程、批准身份、完整测试计划和配置指纹；结果必须先保存，才可能修改本次生产内核的选择。控制结果无法确认时停止自有内核。

## 保存和维护

偏好和下次时间存于私有 `settings.json` 的 `benchmark`、`nextBenchmarkUtc`。逐轮结果和历史位于私有 `benchmarks/`；未完成任务不会被当成新鲜的全通过结果。UI 同时显示当前设置与本次结果实际使用的轮数/超时/协议，避免把短时验收当作默认完整任务。

公开资源可能更新。必要时在本机数据目录准备 `desktop-targets.json`，使用管理器默认五项的完整列表（含 id/label/url/kind/expectedType），仅替换原三个资源的公开 CDN URL；不能删掉失败项目来获得全通过，也不能加入账号地址、查询凭据或未批准域名。两个匿名根入口保持不变。

构建检查除原项目外还包括：

```powershell
dotnet run --project app/ClaudeSafe.Manager.BenchmarkTests -c Release
dotnet run --project app/ClaudeSafe.Manager.PolicyTests -c Release
dotnet run --project app/ClaudeSafe.Manager.ScheduleTests -c Release
```

这些默认是离线回归。带 `--live` 的验收命令需要单独准备本机私有配置，不在 CI 中发送真实网络请求。
